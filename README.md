# 🧪 Quiz de Química: Funções Orgânicas & Isomeria

Este é um projeto acadêmico desenvolvido para a disciplina de **Química**, focado no aprendizado interativo de funções orgânicas e conceitos de isomeria. O software cumpre os requisitos de desenvolvimento de uma aplicação/jogo digital pedagógico.

---

## 📋 Informações do Projeto
* **Instituição:** SESI Referência
* **Área de Conhecimento:** Trabalho de Natureza (Química)
* **Temática Central:** Funções Orgânicas e Isomeria Plana/Geométrica
* **Formato de Entrega:** Aplicação Web (Acessível via Navegador)

---

## 🚀 Funcionalidades
* **Interface Responsiva:** Design limpo e moderno adaptável a computadores e celulares.
* **Barra de Progresso Dinâmica:** Mostra graficamente o avanço do usuário ao longo do teste.
* **Feedback Instantâneo:** Mostra a resposta correta e a incorreta imediatamente após o clique, otimizando o estudo.
* **Contador de Pontuação:** Painel final com o total de acertos do grupo ou aluno.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando tecnologias puras da Web (Vanilla Architecture), garantindo leveza e carregamento instantâneo sem necessidade de instalar dependências:

* **HTML5:** Estruturação semântica das telas e componentes de quiz.
* **CSS3:** Estilização moderna utilizando variáveis nativas, layouts em Grid/Flexbox e gradientes visuais.
* **JavaScript (ES6):** Motor lógico responsável pela manipulação do DOM, controle do banco de dados de perguntas e cálculo de score.

---

## ⚙️ Como Executar o Projeto Localmente

1. Faça o clone deste repositório ou baixe o arquivo `.zip`.
2. Navegue até a pasta raiz do projeto.
3. Dê um duplo clique sobre o arquivo `index.html` para abri-lo diretamente em qualquer navegador web moderno (Chrome, Edge, Firefox, Safari).
